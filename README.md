This repo has a much of demo projects to understand the usage of latest AI tool AntiGravity. Using antigravity I have buit 3 applications.

1. The first application is a web app called "Expense Tracker". Using which the user can add expenes and income. It aslo allow the user to keep track of their expenditure.

2. The second is a mobile applicaiton used for tracking habits. Using the "Habit Tracker" the user can add new habits and check-in its progress. It also shows the number of day streaks maintained by the user. The application is supported in Android and MacOS.

3. For the third application, I have buit a neural network based MNIST classifer. Antigravity built a very prompt clasification model with accracy of about 99%.


This repo also contains the generative AI demo project to generate image from a text promp. I used a pre-trained model "runwayml/stable-diffusion-v1-5" to build a very imaginative image from my prompt. I also built a project to do image comprehension. The model takes in a image and gives creative description and builds a story based the image. For this purpose, I also used a pre_tranined model "llava-hf/llava-1.5-7b-hf" and it produced a cinematic explanation for the image.
